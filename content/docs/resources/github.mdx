## 只作为查证和外链

以下资料质量很高，但许可证不适合直接批量复制或改编：

- [Go 101](https://github.com/go101/go101)：用于核对 Go 类型、语义和性能细节。
- [Go 语言原本](https://github.com/golang-design/under-the-hood)：用于理解调度器、内存、编译器和工具链。
- [roadmap.sh](https://roadmap.sh/backend)：用于参考主题目录和学习层次。
- [You Don't Know JS](https://github.com/getify/You-Dont-Know-JS)：用于查证 JavaScript 语言机制。

## 内容生成规则

每篇文章至少需要经过四步：

1. 从前端知识目录选取一个熟悉概念。
2. 找到对应的 Go 机制，并标记类比成立范围。
3. 使用 Go 官方文档或者一手设计资料校验结论。
4. 加入可以运行的练习和真实工程问题。

网站只记录重新组织和独立撰写的内容，不把第三方仓库正文直接复制进来。
