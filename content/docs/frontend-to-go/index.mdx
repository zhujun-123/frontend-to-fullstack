## 映射不是翻译

“Promise 对应 Goroutine”只说对了一小部分。它们都能参与并发任务，但 Promise 表示未来结果，Goroutine 表示一个正在独立执行的函数。真正完整的映射还需要 Channel、WaitGroup、errgroup 和 Context。

因此，每个专题都使用三种关系标记：

| 关系 | 含义 |
| --- | --- |
| 同一抽象 | 解决的问题基本一致，可以直接迁移已有认知 |
| 部分类比 | 能帮助入门，但运行机制或者约束不同 |
| 危险类比 | 表面相似，直接照搬会产生错误设计 |
