## 相似点：不要求显式声明实现关系

```ts
interface Writer {
  write(data: string): void;
}

const logger = {
  write(data: string) {
    console.log(data);
  },
};
```

```go
type Writer interface {
    Write([]byte) (int, error)
}
```

只要具体类型拥有匹配的方法集合，就能够满足 Go Interface，不需要写 `implements`。

## 关键差异

- TypeScript 类型主要用于编译期检查，输出 JavaScript 后接口会被擦除。
- Go Interface 是运行时值的一部分，包含动态类型和动态值。
- Go 的方法接收者是值还是指针，会影响方法集合以及是否满足接口。
- Go 更倾向于在使用方定义小接口，而不是提前设计庞大的公共接口。

## 从前端思维迁移

不要把一个 TypeScript 大型 DTO Interface 原样搬成 Go Interface。数据结构通常应该使用 Struct；Interface 更适合描述行为边界，例如存储、发送、读取或者计费能力。
