## 问题与系统不变量

调用方希望依赖行为而不是具体实现，但运行时仍必须知道实际类型和数据地址，才能完成方法调用、类型断言与比较。Interface 的动态类型一旦存在，即使动态值是 nil，整个接口值也不是 nil。

## 前端认知起点

TypeScript 和 Go 都允许一个类型在没有显式 `implements` 的情况下满足契约。前端可迁移“面向最小能力编程”的思路；需要放弃的是“Interface 只存在编译期”和“null 判断只看数据部分”。

## 最小心智模型

```text
interface value = (dynamic type, dynamic value)
nil interface   = (nil, nil)
typed nil       = (*MyType, nil)
```

方法集合决定可赋值性：类型 `T` 的 Method Set 包含值接收者方法；`*T` 的 Method Set 同时包含值接收者与指针接收者方法。

## Go 1.26.5 当前实现

Runtime 中空接口可抽象为类型指针加数据指针，非空接口还持有与 Interface 方法表相关的 `itab`。这是理解 typed nil 的实现依据，但业务代码应依赖语言规范，不依赖字段布局。

```go
type Counter int

func (c Counter) Value() int  { return int(c) }
func (c *Counter) Increment() { (*c)++ }
```

`Counter` 和 `*Counter` 都满足只要求 `Value()` 的接口；只有 `*Counter` 满足要求 `Increment()` 的接口。编译器允许对可寻址值自动取地址调用指针接收者方法，不等于 `Counter` 的 Method Set 包含该方法。

## 类比成立范围

- 两者都适合在使用方定义小接口。
- 两者都支持结构化满足关系，不要求显式声明实现。
- Mock、Adapter 和依赖倒置的设计动机相通。

## 类比失效边界

- TypeScript Interface 编译后通常被擦除；Go Interface 是运行时值。
- Go Interface 描述行为，DTO 数据通常应使用 Struct，而不是把每个数据结构都变成 Interface。
- `any` 不等于 TypeScript `any`：取出动态值仍需类型断言或 Type Switch。
- Interface 动态类型不可比较时，对两个接口做 `==` 可能 panic。

## 可运行实验

```bash
cd examples/go-runtime
go test ./labs/interfaces
go test -bench=. -benchmem ./labs/interfaces
```

正常实验验证值与指针的 Method Set 差异。错误边界实验验证 `io.Writer` 中装入 `(*NilWriter)(nil)` 后不等于 nil。Benchmark 只展示调用路径可测，不应用单一微基准决定是否移除接口。

## 真实生产故障场景

Repository 实现返回 `*QueryError(nil)` 作为 `error`。上层判断 `err != nil` 成立，误走失败分支并返回 500；日志格式化时又调用了没有 nil 防护的 `Error()`，造成二次 panic。正确做法是在没有错误时直接返回裸 `nil`。

## 证据与排查

| 证据 | 重点 |
| --- | --- |
| `%T` 与 `%#v` 日志 | 同时记录动态类型和值，避免只打印 `<nil>` |
| 编译错误 | Method Set 不满足时查看接收者是 T 还是 *T |
| Panic 栈 | 是否在 Interface 比较、类型断言或 nil 接收者方法中失败 |
| CPU Profile | 热路径是否出现 Interface 转换或反射成本 |
| Escape Analysis | 装入 Interface 是否让值逃逸；只作为优化线索 |

## 常见错误与版本变化

- 返回 `error` 时不要先把具体错误指针设为 nil 再返回，应直接 `return nil`。
- 编译器的自动取地址调用语法不会改变 Method Set。
- “接受 Interface，返回 Struct”是经验法则，不是不可违反的语言规则。
- Go 1.18 起 Interface 还用于泛型约束的 Type Set；包含类型元素的约束接口通常不能直接作为普通运行时值使用。
- Runtime 的 `iface`/`eface` 布局不是公开 API，源码引用固定到 go1.26.5。
